# Tech badge icons

Brand paths are sourced from [Simple Icons](https://github.com/simple-icons/simple-icons), with readable colors on the profile's dark surface. See the upstream [license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md) and [brand disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md).

Framework marks identify specialist tools where a standalone mark is unavailable: PyTorch for timm and Stable-Baselines3, Hugging Face for Transformers, Meta for SAM, Ultralytics for YOLO, and PostgreSQL for its pgvector extension. SQL, XGBoost, and Gymnasium use authored database, decision-tree, and game-environment symbols respectively. These are identification badges, not endorsements.
